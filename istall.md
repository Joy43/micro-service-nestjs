# 🚀 EventFlow Manage Installation Guide

This guide will help you set up and run the **EventFlow Manage** application on your local machine.

---

## 📦 1. Create a New NestJS Project

```bash
nest new my-project
```

---

## 📚 2. Generate Common Library

```bash
nest g lib common
```

---

## 🏗️ 3. System Design (Architecture Planning)

🔗 [https://app.diagrams.net/?src=about](https://app.diagrams.net/?src=about)

---

## 🔌 4. Install Microservices & Kafka Dependencies

```bash
pnpm add --save @nestjs/microservices
pnpm add --save kafkajs
```

---

## 📨 5. Generate Kafka Library

```bash
nest g lib kafka
```
